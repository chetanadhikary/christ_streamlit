# Streamlit Workshop Delivery Guide

## Duration

Approximate duration: 3 hours


## Audience

Engineering students with basic Python knowledge.


# Session Flow


## 1. Introduction (15 minutes)

Explain:

- What is Streamlit?
- Why rapid application development?
- Difference between traditional web development and Streamlit


Demo:

Run:

streamlit_basics/01_hello_streamlit


---

## 2. Interactive Applications (30 minutes)

Module:

streamlit_basics/02_widgets


Concepts:

- Inputs
- Variables
- Dynamic output


Exercise:

Create a student profile application.


---

## 3. Data Applications (40 minutes)

Module:

streamlit_basics/03_data_loading


Concepts:

- CSV files
- Pandas DataFrames
- Filtering


Exercise:

Add additional filters.


---

## 4. Visualization (40 minutes)

Module:

streamlit_basics/04_visualization


Concepts:

- Plotly charts
- Data interpretation


Exercise:

Create a new visualization.


---

## 5. Dashboard Development (50 minutes)

Module:

streamlit_basics/05_dashboard_layout


Concepts:

- Dashboard design
- KPIs
- Filters
- Layout

student_dashboard
