# Final Project: Student Analytics Dashboard

## Objective

Build an interactive analytics dashboard using Streamlit.

You will apply concepts learned in:

- Streamlit basics
- Widgets
- Pandas
- Data filtering
- Plotly visualisation
- Dashboard layout


## Requirements

Your dashboard should include:


### 1. Data Loading

Load the student dataset using Pandas.


### 2. Filters

Add interactive filters:

- Department
- Semester
- CGPA


### 3. Key Metrics

Display:

- Total students
- Average CGPA
- Placement percentage


### 4. Visualizations

Include at least:

- Department-wise student count
- CGPA analysis
- Placement analysis


## Bonus Challenges

Add:

- Student ranking
- Additional charts
- Better dashboard design
- Additional insights
