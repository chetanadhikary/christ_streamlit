# Streamlit Workshop

## Learning Objectives

By the end of this workshop you will learn:

- What Streamlit is
- Creating interactive web applications using Python
- Loading data using Pandas
- Adding filters
- Creating visualizations
- Building a student analytics dashboard


## Getting Started

### Option 1: GitHub Codespaces

1. Click Code
2. Select Codespaces
3. Create codespace on main
4. Wait for setup
5. The dashboard opens automatically
